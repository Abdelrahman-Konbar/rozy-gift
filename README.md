# هدية روزي 💜

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## بناء نسخة النشر

```bash
npm run build
```

سينتج مجلد `dist/` الجاهز للنشر.

## النشر على Vercel أو Netlify

ارفع هذا المجلد إلى GitHub، ثم:

- **Vercel:** اختر **Add New → Project** ثم المستودع. الإعدادات تلقائية: Build command `npm run build` وOutput directory `dist`.
- **Netlify:** اختر **Add new site → Import an existing project** ثم المستودع، وبنفس الإعدادات: `npm run build` و`dist`.

لا توجد قاعدة بيانات أو تحليلات أو تسجيل دخول؛ كل المحتوى والأصول تعمل من المتصفح نفسه.

## تعديل المحتوى لاحقًا

كل محتوى الهدية الأساسي موجود في `src/data/content.ts`، والصورة والأغنية في `public/assets/` باسم `couple.png` و`layla.mp3`.

وللتعديل دون لمس الكود، افتح `/#/edit` بعد تشغيل الموقع محليًا أو نشره. اللوحة تحفظ التغييرات في المتصفح، وتتيح معاينة مباشرة، وتصدير/استيراد نسخة JSON. هذه لوحة تحرير محلية وليست نظام دخول أو حماية أمنية.
